# AIOPS_RK

## 🐍 Python Playground for Class 6

An interactive, step-by-step Python course for school students. It has 10 lessons, quizzes,
challenges that check the student's program, a scorecard with a trend chart, a sandbox where
students can try code, and mini projects.

**Quick start:**
1. Install Python 3 from <https://www.python.org/downloads/> (on Windows tick *"Add Python to PATH"*).
2. Download this repo (**Code → Download ZIP**) and unzip it.
3. Open the `python_class6_playground` folder and:
   - **Windows:** double-click `run_playground.bat`
   - **Mac/Linux:** run `./run_playground.sh`
   - **Or:** `python playground.py`

**No install?** Open `python_class6_playground/web/index.html` in a browser. The whole course runs there too.

Full guide, lesson list and teacher notes: [python_class6_playground/README.md](python_class6_playground/README.md)

## 🌐 HTML Playground for Class 6–7

Starts with Chapter 9 "Build a Better Web Page" missions, then a step-by-step HTML course with a live preview, quizzes, self-checking challenges and a
scorecard that shows each student's trend. Works on phones and iPads too.

**Quick start:** open `html_class6_7_playground/index.html` in any browser.
Full guide: [html_class6_7_playground/README.md](html_class6_7_playground/README.md)

## 🛡️ IndiKids – Parental Control

A Kids360-style app for parents: screen time limits, scheduled downtime, live location, app usage reports,
"ask for more time" and SOS. It has a parent app (**IndiKids**) and a child app (**IndiKids Child**).

**Quick start:** `cd indikids && node server.js`, then open <http://localhost:8080/demo.html> to try both phones side by side.
Full guide: [indikids/README.md](indikids/README.md)
